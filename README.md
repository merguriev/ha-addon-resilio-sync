# Resilio Sync — дополнение для Home Assistant

Копирует бэкапы Home Assistant на ваши устройства (ПК, сервер, NAS, телефон) через
[Resilio Sync](https://www.resilio.com/sync/). Работает внутри HA OS / Supervised.

## Как это работает

- Папка бэкапов HA подключается **только на чтение**. Раз в N минут новые бэкапы копируются в
  `/share/resilio/ha-backups` с понятными именами: `2026-11-06_0501_Automatic_backup_..._<slug>.tar`.
  Хранятся последние `keep_backups` (по умолчанию 7), независимо от того, сколько хранит сам HA.
- Resilio Sync синхронизирует эту папку. Ключ папки создаётся при первом запуске, а в
  **журнал дополнения** выводится ключ **только для чтения**.
- На других устройствах добавьте папку по этому ключу. С ключом «только чтение» устройство не может
  ничего изменить или удалить в HA.
- Бэкапы HA обычно зашифрованы ключом шифрования HA, поэтому на других устройствах они нечитаемы без него.

## Установка

1. **Настройки → Дополнения → Магазин дополнений → ⋮ → Репозитории** и добавьте адрес
   `https://github.com/merguriev/ha-addon-resilio-sync`.
2. Установите **Resilio Sync** и запустите его. Первая сборка занимает несколько минут.
3. Откройте **Журнал** и скопируйте ключ «только для чтения».
4. В Resilio на ПК или сервере выберите «+» → «Ввести ключ или ссылку», вставьте ключ и укажите папку.

## Обновления

При каждом запуске дополнение проверяет официальный apt-репозиторий Resilio и ставит новую версию
(пакет проверяется подписью Resilio). Чтобы обновления приходили сами, перезапускайте дополнение по
расписанию, например автоматизацией с `hassio.addon_restart` раз в неделю. Текущая версия записывается в
`/share/resilio/.version`. При обновлении дополнение шлёт в HA событие `resilio_sync_updated`
(`old`, `new`), на него можно повесить уведомление.

## Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `device_name` | Home Assistant | имя устройства в Resilio |
| `keep_backups` | 7 | сколько последних бэкапов держать в папке синхронизации |
| `copy_interval_minutes` | 15 | как часто проверять новые бэкапы |
| `listening_port` | 55555 | порт Resilio (TCP/UDP) |
| `debug` | false | подробный журнал Resilio (для диагностики) |
| `known_hosts` | — | список «ip:порт» других устройств с Resilio, если они не находят друг друга сами. Порт на ПК: Resilio → Настройки → Подключение → «Порт» |

Веб-интерфейса нет: папка задаётся конфигурацией, а Resilio при этом веб-интерфейс отключает.
Устройства в локальной сети находятся автоматически, через интернет — через трекер и ретранслятор Resilio.
