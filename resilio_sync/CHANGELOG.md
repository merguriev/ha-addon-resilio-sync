# Changelog

## 1.3.0

- Режим с веб-интерфейсом Resilio (по умолчанию, порт 8888): Resilio 3.x не синхронизирует без активированной
  лицензии (бесплатной после регистрации или Pro), а активировать её можно только в интерфейсе. Состояние
  Resilio в этом режиме сохраняется между запусками. Прежний режим без интерфейса — `webui: false`.

## 1.2.3

- Исправление 1.2.2 действительно включено (сброс состояния Resilio при запуске).

## 1.2.2

- Состояние Resilio сбрасывается при запуске: папка бралась из прошлого sync.dat, и настройки (known_hosts) не применялись — устройства не подключались.

## 1.2.1

- Опция `debug`: подробный журнал Resilio для диагностики подключения.

## 1.2.0

- Настройка `known_hosts` («ip:порт» других устройств): если устройства не находят друг друга сами
  (трекер Resilio недоступен, поиск в локальной сети заблокирован).

## 1.1.1

- Событие `resilio_sync_updated` {old, new} в HA при обновлении Resilio — для уведомлений.

## 1.1.0

- Автообновление Resilio Sync: при каждом запуске проверяется официальный apt-репозиторий (с подписью) и ставится новая версия; версия пишется в /share/resilio/.version.

## 1.0.3

- Токен Supervisor берётся и из окружения s6 (уведомление с ключом не создавалось).

## 1.0.2

- Ключ «только для чтения» дублируется уведомлением в HA; выключен отладочный журнал Resilio.
- Понятные имена бэкапов HA сохраняются как есть; копии сохраняют дату файла (иначе очистка могла удалить свежие).

## 1.0.1

- Resilio Sync ставится из официального apt-репозитория с проверкой подписи (CDN архивов из части регионов отдаёт 404).

## 1.0.0

- Первая версия: копирование бэкапов HA в папку синхронизации с понятными именами, хранение последних N,
  Resilio Sync с ключом папки, ключ «только для чтения» в журнале.
